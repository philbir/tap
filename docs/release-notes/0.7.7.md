# Tap 0.7.7 Release Notes

A maintenance release: every pending dependency update, taken in one pass.

## Dependencies

Twenty-two Dependabot pull requests, landed together. Four ecosystems, none of which
interact, and merging them one at a time would have meant twenty-two lockfile rebases to
arrive at the same place.

## The one that got checked properly

`@codemirror/view` is not an ordinary bump in this repo. CodeMirror's `Facet` and
`Extension` identity is `instanceof`-based, so if `@codemirror/state` or `@codemirror/view`
ever resolve to two copies, every extension becomes unrecognisable and CodeMirror throws
while rendering — taking every editor surface down with it. It fails at **runtime**, with a
perfectly green build, and 0.5.0-beta.2 shipped exactly that.

Two independent mechanisms can mint the second copy: `node_modules` hoisting, and Vite's
dependency optimizer bundling a copy into a consumer's chunk even when only one exists on
disk. So this one was verified rather than trusted — one `@codemirror/state` (6.7.1) and one
`@codemirror/view` (6.43.11) on disk, and the built bundle actually rendered against the
sample workspace, with editors mounting on the GraphQL body mode. That path goes through
`cm6-graphql`, the transitive consumer most able to fork the tree.

While there: `ui-studio`'s `resolutions` pin read `^6.43.8` where its dependency read
`^6.43.9`. Both resolve to the same version, so nothing was broken — but a mismatched pair
is an invitation to correct the wrong half later, so they now agree.

## Upgrading

Nothing to do. No workspace-format, CLI, or API changes.

If you are on Windows and skipped 0.7.6, take it: that release fixed a bug that opened the
app to a permanently blank window. See the [0.7.6 notes](0.7.6.md).

`.md` workspace files still load with a `W_LEGACY_EXTENSION` warning for the whole 0.7.x
line; `tap-studio migrate` converts a workspace when you're ready. Removal is still targeted
at 0.8.0.
