# Tap 0.2.1 Release Notes

Tap 0.2.1 focuses on making streaming traffic easier to inspect and making the sample experience more complete. The release adds live Server-Sent Events visibility in the inspector, expands the sample app so it can exercise every configured tap proxy, and improves the docs site with screenshots of the main workflows.

## Highlights

- Tap now recognizes `text/event-stream` responses and captures SSE activity without blocking the stream from reaching the client.
- The inspector UI includes live stream indicators, event counts, and a dedicated SSE view for streamed request records.
- The sample Aspire app now includes a browser client for sending normal requests and opening SSE streams through each configured tap.
- The documentation site now shows screenshots for Aspire integration, CLI output, tunnel flow, and inspector usage.

## What Changed

- Added streaming-aware response capture so normal responses are still buffered for inspection, while SSE responses are forwarded and flushed in real time.
- Added incremental inspector updates for streamed events, including stream completion state.
- Updated the CLI and inspector feed to work with the new request/update event model.
- Added sample API endpoints for endpoint discovery and SSE testing.
- Added a new Vite/React `Sample.Client` resource launched by the Aspire AppHost.
- Cleaned up the README hero by removing a duplicate heading.

## Compatibility

- No breaking user-facing changes are expected.
- The sample AppHost now uses `Aspire.Hosting.JavaScript` for the new Vite sample client.
- The new sample client follows the existing Yarn 4.9.1 and Vite tooling used elsewhere in the repository.
